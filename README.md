# CurbWhiz — website

Static pages for the CurbWhiz iPhone app: the home page (`index.html`), the support guide (`support.html`) and the privacy policy (`privacy.html`).

The web app that used to be served from this repo was retired on November 11, 2026. `sw.js` only removes that app's offline cache from browsers that still have it. The source of the home page is kept in the private app repo under `site/`.
